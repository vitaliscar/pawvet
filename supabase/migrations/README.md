# Deprecado

Este proyecto migró de Supabase (Postgres) a [PocketBase](https://pocketbase.io/).
Estas migraciones SQL ya no se ejecutan ni reflejan el esquema actual.

El esquema vigente está en [`pocketbase/pb_schema.json`](../../pocketbase/pb_schema.json)
(importar desde el Admin UI de PocketBase: Settings → Import collections).

Se conservan aquí solo como referencia histórica del modelo de datos original.
